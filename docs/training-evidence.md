# 비개발자용 설명

근력 분석은 운동일지에 실제로 적힌 세트와 중량을 읽고, 비교할 수 있는 조건과 확인이 필요한 조건을 나눈다. 같은 실제 장비에서 `40kg × 10회 → 45kg × 10회`로 기록이 바뀌고 외부 중량 역할·중량 기준·세트 수·RIR·확인한 순차 수행 맥락이 같다면 기록상 증가로 표시한다. 이를 실제 근육 증가량이나 진단으로 바꾸지 않는다.

예전 사진처럼 RIR과 한쪽·합산 중량 기준이 비어 있어도 숫자를 숨기지 않는다. `50kg × 10회 → 50kg × 12회`는 관찰된 기록 변화로 보여 주되, 같은 노력 수준에서 수행이 향상됐다고 확정하지 않는다. 다른 머신의 표시 중량을 서로 환산하지 않고, 몸무게나 빈 값을 0kg으로 채우지도 않는다.

최근 28일의 직접·간접 세트는 따로 표시한다. 벤치 프레스 일반 세트 3개는 이 제품 분류에서 가슴 직접 3개, 어깨·삼두 각각 간접 3개다. 이를 합쳐 총 9개짜리 자극이나 건강 점수를 만들지 않는다. RIR을 모르는 세트도 기록된 세트 수에는 남지만, 유효 세트나 충분한 자극이라고 이름 붙이지 않는다. W는 준비 세트로 제외하며 D·A·그 밖의 표시는 원문을 유지하고 별도 표시 세트로 집계한다. 드롭세트나 보조 세트라고 자동 해석하지 않는다.

프로그램은 일반 성인을 위한 시작 예시다. 주 1~6회, 회당 20~150분, 헬스장·덤벨이 있는 집·추가 장비 없는 맨몸 조건을 반영한다. 운동 경력이 없으면 주간 횟수로 고급자 여부를 추측하지 않는다. 맨몸만으로는 등·이두의 점진적 부하에 한계가 있으며, 시간이 짧거나 장비가 없어 요청한 부위의 직접 동작을 넣지 못하면 한계에 명시한다. 모든 사람에게 완벽한 개인 PT나 대회·재활 처방이라는 주장은 하지 않는다.

통증 때문에 중단해야 한다고 기록하면 수행 기록이 좋아도 중단 안내가 먼저다. 반복적인 수행 저하와 최근 회복 관련 자기보고가 함께 있어야 디로드를 **검토할 이유**로 표시한다. 하루의 낮은 기록만으로 과훈련이나 디로드 필요를 단정하지 않는다. 성별·체중·체지방률에서 특정 기구의 적정 중량을 만들어 내지 않는다.

정책·계산 변경: 별도 근력 분석과 시작 프로그램에 저장·일정·실제 수행 비교·다음 계획 조정을 연결했다. 근력 모듈이 영양 목표·등열량 배분·완료일 스냅샷을 변경하지는 않는다. 순수 분석 함수는 사용자 기록이나 프로필을 수정하지 않고, 화면의 명시적 저장은 별도 검증 경계를 통과한다.

## 실제 해석 규칙

- 기간은 선택 날짜를 포함한 28일이다. 미래 기록과 잘못된 날짜는 제외한다. 날짜가 비면 모든 빈 날짜를 휴식일로 채우지 않는다.
- 같은 날짜의 오전·오후 세션은 따로 남긴다. 같은 날 세션끼리는 피로·순서의 영향을 분리할 수 없어 장기 수행 변화 판정을 하지 않는다.
- 같은 기록 ID의 완전 복사본은 하나만 사용하고, 동일 ID에 상충하는 내용은 집계에서 제외한다. 같은 이미지 해시·날짜·시간·세트 내용의 사본도 중복 집계하지 않는다.
- 같은 운동을 한 세션 안에서 여러 블록으로 기록하면 각각 보존하고 선행 맥락도 따로 계산한다. A→B→A의 앞뒤 A를 합치지 않는다. 표시 순서는 실제 순서가 확인된 경우에만 수행 순서로 사용하며 슈퍼세트·교차 수행의 선행 세트 수를 순차 수행처럼 계산하지 않는다.
- 대표 세트는 확인된 일반 세트 중 표시 중량이 가장 큰 세트이고, 같으면 반복 수가 많은 세트다. 이 선택은 제품의 설명 가능한 표시 규칙이며 추정 1RM 계산이 아니다. 일반 세트가 없으면 표시가 붙은 세트도 관찰값으로는 남기되 비교 판정을 하지 않는다.
- 비교 판정에는 서로 다른 날짜, 동일 장비 키, 확인된 외부 중량 역할과 한쪽 또는 합산 규약, 동일한 기록 RIR·일반 세트 수·확인된 순차 수행 맥락이 필요하다. 같은 날짜의 다른 세션 선후도 추측하지 않는다. 한 변수만 바뀌면 중량 또는 반복 수의 기록 변화로 표시한다. 중량과 반복 수가 동시에 바뀌면 mixed로 남긴다. 보조 중량과 순서 미확인은 관찰로 남으며 반복 저하·디로드 근거로 승격하지 않는다.
- 몸무게 운동의 외부 중량 0과 실제 체중 부하를 같게 취급하지 않는다. 현재 체중을 과거 운동에 끼워 넣어 비교하지 않는다.
- 사용자에게 확인된 운동 ID가 있으면 기록의 운동 선택을 우선한다. 별명 매핑은 확인된 것만 적용하며 장비 키·규약으로 범위를 좁힌다. 확인되지 않은 이름에 유사 문자열만으로 임의 대응하지 않는다.
- 일반 종목명 카탈로그는 머신 플라이(펙 덱)·머신 숄더 프레스·머신 암 컬·덤벨 불가리안 스플릿 스쿼트·덤벨 스티프 레그 데드리프트·케이블 암 풀 다운·스미스 시티드 숄더 프레스·뉴트럴 그립 랫 풀 다운·스미스 언더그립 벤트 오버 로우·케이블 로프 푸시 다운을 포함한다. 이름에 명시된 그립·동작·장비 변형은 기존 일반 종목과 별도 ID로 보존한다. 이번 추가는 인식 누락 보완이며 기존 프로그램 종목과 세트 처방은 바꾸지 않는다.
- 정확한 일반 동작명과 브랜드·모델 확인은 별개다. `머신 플라이`를 가슴 동작으로 분류해도 장비 키가 없는 두 머신의 부하를 비교하지 않는다. 카탈로그에 없는 Drax·Infinity·STA7000 모델명을 접두어 제거로 추측하지 않고, 실제 동작과 장비를 확인한 사용자 매핑이 필요하다. 모든 운동명을 지원한다고 주장하지 않는다.
- `W웜업풀업` 같은 이름은 풀업 동작을 식별할 수 있지만, 이름에서 세트별 준비 여부·RIR·체중 부하를 만들어 내지 않는다. 준비 세트 제외는 각 세트에 명시된 W에만 적용한다. 표기 없는 세트는 일반 기록 수에 남을 뿐 충분한 자극 또는 성장 유효 세트라는 뜻이 아니다.
- 불확실한 과거 OCR의 총 세트·총 볼륨은 부위별 숫자로 쪼개지 않는다. 기록된 Cal은 이 모듈에서 실제 소모량으로 재사용하지 않는다.
- 통증은 마지막으로 명시한 상태를 읽는다. 미입력을 통증 해소로 취급하지 않으며 현재 상태가 달라졌으면 명시적으로 갱신할 필요가 있다. 여기서 통증의 원인이나 치료법을 판단하지 않는다.

### 현재 상태와 질병 뒤 복귀

[IOC 급성 호흡기 질환 합의(2022)](https://pubmed.ncbi.nlm.nih.gov/35863871/)는 운동 재개와 질병 전 수행 수준으로의 복귀를 구분하고, 증상 확인과 운동 중·직후·다음 날 반응을 보며 부담을 조절한다. [원문](https://cris.brighton.ac.uk/ws/files/33068214/Clean_copy_Revised_BJSM_Part_1_IOC_Consensus_Acute_respiratory_infections_v2_May_18.pdf)은 발열·전신 증상·흉부/호흡 증상이나 비정상적인 운동 반응에서 의료 평가를 우선한다. 앱이 `아픈 상태 / 회복 중` 자기보고만으로 질병명·중증도·회복 완료나 운동 허용 여부를 진단하지 않는다. 임상 평가용 운동 도전 검사에 제시된 숫자를 모든 사용자에게 자동 처방하지 않는다.

기준 날짜의 상태와 이전 7일에 있었던 상태는 따로 보존한다. 오늘 낮은 컨디션·좋지 않은 수면·수행 저하 등이 겹치거나 피로가 높다고 명시하면, 실제로 완료한 세트는 그대로 읽되 다음에는 몸풀기에서 그 수행이 제어되는지 확인하고 버거우면 부담을 낮추거나 쉬도록 한다. 아픈 상태이면 기록을 다시 채우기보다 회복을 우선하고, 회복 중이면 이번 수행과 운동 뒤·다음 날 반응에서 이어간다. 숫자 반복 증가 제안은 현재 행동이 아닌 회복 뒤 대안으로 둔다. 현재 상태가 좋아졌다고 명시한 뒤에는 과거 불량 상태만으로 진행 선택을 계속 막지 않는다.

수면 6시간 미만, 두 자기보고 영역의 조합과 `피로 높음`에 대한 위 행동 조정은 **제품 선택**이지 개인의 필요 수면·질병·탈훈련·부상 위험을 판정하는 생리학적 경계가 아니다. 수면 시간과 수면 질은 같은 영역으로 읽어 중복 경고로 세지 않으며, 단 한 번의 좋지 않은 수면에는 몸풀기 반응에 따른 조건부 선택을 제공한다. 미입력 수면 시간을 0으로 만들지 않는다. [훈련 반응의 주관적·객관적 관찰에 대한 체계적 문헌고찰](https://pubmed.ncbi.nlm.nih.gov/26423706/)은 자기보고의 유용성을 지지하지만 한 값으로 원인이나 다음 수행 능력을 확정하지는 않는다. 통증·임상적 제한, 명시한 디로드·복귀 목적과 원문 검증은 이 진행 선택보다 우선한다.

### 종목별 부하를 읽는 경계

[IOC 부하 관리 합의(2016)](https://doi.org/10.1136/bjsports-2016-096581)는 종목 훈련 외에도 경기·심리적 부담·여행·개인 회복을 함께 살피고, 전원에게 하나의 훈련 증가식을 적용하지 않는다. 기록 없는 날은 실제 휴식이나 여행·질병의 증거가 아니다. 명시한 중단 사유와 실제 복귀 기록은 별개로 읽으며, 공백 기간만으로 능력 감소율을 추정하지 않는다.

달리기의 거리·시간, 사이클의 파워·거리, 수영의 영법·거리·수영장 조건, 구기의 실제 참여 시간과 경기/훈련, 복합 종목의 구간은 서로 다른 관찰이다. 시간만 기록해도 실제 활동으로 인정하지만 빠른 페이스·낮은 심박·높은 파워가 자동으로 체력 향상이나 완전한 회복의 측정이 되지는 않는다. 표시 kg와 반복을 달리기 거리 또는 전신 근성장 유효 세트로 바꾸지 않는다. [HYROX 공식 경기 설명](https://hyrox.com/the-fitness-race/)의 달리기와 기능 운동 구간도 각각 기록할 맥락이지 보디빌딩 세트나 개인 완주 예상으로 환산하는 근거가 아니다.

[2025년 달리기 코호트](https://pmc.ncbi.nlm.nih.gov/articles/PMC12421110/)는 최근 최장 거리 대비 단일 세션 거리 증가와 부상 발생의 연관성을 관찰했지만 주간 증가나 ACWR 결과는 같지 않았다. [초보 달리기 무작위 실험](https://pubmed.ncbi.nlm.nih.gov/17940147/)의 주간 10% 증가 규칙도 부상 예방을 보장하지 않았다. 따라서 큰 기록 증가를 다음 행동에서 살펴보되, 10%를 모든 종목의 안전선으로 사용하거나 ACWR을 개인 부상 확률로 표시하지 않는다.

카탈로그의 동작 분류에는 [ACE의 펙 덱 원 연구 보고](https://www.acefitness.org/certifiednews/images/article/pdfs/ACE_BestChestExercises.pdf), [ACE 스트레이트 암 프레스다운 설명](https://www.acefitness.org/resources/everyone/exercise-library/334/straight-arm-pressdown/), [스티프 레그와 루마니안 데드리프트 비교 실험](https://pubmed.ncbi.nlm.nih.gov/35162922/)을 참고했다. 팔꿈치 굽힘을 사용하는 랫 풀 다운과 팔을 편 어깨 폄 동작을 구별하고, 스티프 레그와 루마니안 변형도 같은 수행 비교로 묶지 않는다. 문헌의 동작 설명·근전도 관찰은 분류의 근거일 뿐이다. 직접·간접 세트의 이진 구분은 제품의 대표 해부학적 분류이며 특정 사용자의 근활성·유효 자극량·근성장률 측정이나 장비 환산 계수가 아니다.

## 저장 계획과 실제 수행

### 세션 맥락과 개인 중량 참고

[운동 순서 메타분석](https://pubmed.ncbi.nlm.nih.gov/32077380/)은 먼저 수행하는 종목의 근력 적응이 더 클 수 있음을 보여 준다. 이 결과에서 개인의 순서별 피로율이나 머신 치환 계수를 얻을 수는 없다. [프리웨이트·머신 메타분석](https://pubmed.ncbi.nlm.nih.gov/37582807/)에서도 검사·훈련 방식의 특이성이 나타나므로 운동 계열의 연결과 중량의 동등성을 구분한다.

제품의 중량 참고는 최근 해당 실제 장비의 일반 세트 중 **요청한 반복·RIR에 맞는 실제 세트**를 먼저 사용하고, 없으면 숫자가 확인된 첫 일반 세트로 이어간다. 백오프가 요청 조건에 맞는데 무거운 첫 세트를 대신 제시하지 않는다. 최고 중량 세트와 구별하며 같은 조건의 기록이 없으면 조건이 다른 실제 관찰임을 표시한다. 장비마다 이력을 유지하므로 5:5나 여러 머신 순환에 주 장비를 강요하지 않는다. 선행 세트는 관련 부위가 겹치는 일반 기록을 한 번씩 세는 대표 분류이며 준비·특별 표기·미확인 부위를 따로 둔다. 세션 순서와 순차 수행이 미확인이면 선행 세트 수는 null이다.

개인 치환은 같은 운동 또는 명시적 제한 계열(현재 수평 벤치/덤벨 벤치/머신 체스트 프레스)만 허용한다. 인클라인·플로어 프레스·푸시업을 넓은 밀기 패턴 하나로 환산하지 않는다. 최근 대상 장비 기록이 없고, 확인한 실제 장비·외부 중량 역할·중량 규약·순차 맥락·같은 반복/RIR의 서로 다른 날짜 관찰 짝이 충분할 때만 표시 중량의 개인 관계를 참고한다. 보조/맨몸 부하, 현재 통증·회복 경고, 미확인 예정 맥락은 치환에서 제외한다. 관찰 범위를 벗어난 외삽·연쇄 환산·덤벨 두 배 공식은 없다. 원문 kg는 수정하지 않는다.

직접 기록 우선 기간 28일, 관찰 범위 90일, 새 원본 14일, 관찰 짝의 간격 7일 이하·최소 3개는 **제품의 자료 선별 정책**이다. 최소 짝 수를 채워도 개인의 저항 동등성이 검증되는 것은 아니다. 표시 범위는 관찰 중량 관계의 제한 범위이지 신뢰구간·성공 확률·처방 범위가 아니다. 자료가 부족하면 같은 운동 계열의 맥락과 첫 실제 세션 확인을 이어가되 kg를 발명하지 않는다. 원본 수정·순서 교정은 새 계산에만 반영되며 과거 상담과 완료 목표는 보존한다.

시작 초안은 저장한 프로그램, 실제 날짜에 배치한 계획, 실제 운동일지의 세 단계로 구분한다. 사용자는 프로그램의 운동·세트·반복 범위·RIR·휴식과 선택적 중량·장비 기준을 편집할 수 있다. 날짜에 배치할 때 그 계획을 복사해 두므로 원본 프로그램을 나중에 수정해도 이미 배치한 목표가 몰래 바뀌지 않는다. 빈 날짜나 아직 연결하지 않은 계획은 휴식·실패·수행으로 처리하지 않는다.

- 선호·제외 운동은 저장해 이후 초안을 만들 때 반영한다. 선호는 가능한 장비 안에서 같은 움직임 분류의 후보를 고르고, 제외 후 빠진 움직임이 모두 대체됐다고 보장하지 않는다. 새 운동으로 바꾸면 이전 운동의 개인 중량·장비 기준을 자동 승계하지 않는다. 카탈로그에 없는 가져온 ID·원문 이름은 다른 운동으로 조용히 교체하지 않고 보존한다.
- 계획 이행은 사용자가 연결한 같은 날짜의 실제 일지와 비교한다. 같은 운동 ID의 표기 없는 일반 세트 중 계획한 수만큼의 반복 범위와 최소 RIR 여유를 비교하고, 미입력은 모름으로 둔다. W와 다른 문자 표시 세트는 이 비교에서 제외한다. 계획 중량이 있으면 같은 장비·확인된 중량 규약도 필요하다. 추가 세트는 실제 기록에 남지만 계획한 세트의 평가와 구별한다.
- 같은 종목을 다른 장비 또는 여러 블록으로 계획할 수 있다. 블록 ID는 유일하며 실제 세트 하나는 계획 블록 하나의 평가에만 사용한다. 반복 블록의 대응 순서·장비가 애매하면 달성으로 확정하지 않는다. 프로그램 장비/중량 규약을 바꿨는데 기존 중량 숫자가 그대로이면 자동 승계하지 않고 비운다. 이미 날짜에 배치한 처방은 보존한다.
- `계획 범위 충족`은 기록된 수치 조건의 일치다. 휴식시간·자세·동작 범위·적절한 피로·성장 자극을 확인한 결과가 아니다. 반복 상단 충족도 자동 증량 버튼의 처방 근거가 되지 않으며, 다음 중량은 사용자가 같은 장비와 기준을 확인하고 선택한다.
- 유지·증량 검토·디로드는 수행하지 않은 날짜별 계획에 명시적으로 적용한다. 이유와 재검토 날짜를 저장하고, 조정 전 원래 목표를 보존한다. 디로드의 세트 감소와 RIR 여유 증가는 사용자가 선택하며 정해진 비율·주기로 자동 적용하지 않는다. 완료한 영양 날짜, 이미 수행한 계획, 임상·통증 맥락은 수치 조정에서 보호한다. 회복 경고가 있으면 증량 적용을 막고 확인을 요청한다.
- 재검토 완료 표시는 사용자가 검토했음을 뜻한다. 통증 해소·회복 완료·처방의 효과를 자동 인증하지 않는다. 조정 정보는 현재 선택과 최초 계획을 남기는 구조이며 모든 중간 편집의 완전한 버전 이력은 아니다.

개인 코치의 제약·우선순위·합의는 사용자 확인 후 별도 기억에 저장한다. 후속 약속은 주제·메모·검토 날짜·열림/완료 상태를 보존하며, AI 제안만으로 훈련 계획이나 실제 기록에 적용하지 않는다. 최근 기록과 질문에 관련된 일부 과거 맥락을 대화에 연결하지만, 누락 없는 평생 기억이나 관찰하지 않은 운동 기술 평가를 보장하지 않는다. AI의 수치 출처 확인과 자유 문장 검증의 차이는 [영양·코칭 근거 문서](evidence.md)에 정리했다.

## 기술 검증

### 선택적 운동 의도와 세트 체감

운동 의도는 평소 운동·디로드·가볍게·기술 연습·시간 부족·복귀·시험 중 사용자가 고른 선택이다. 미선택은 미확인이며 일지 숫자가 낮아졌다는 이유로 디로드나 회복 실패를 만들어 넣지 않는다. 세트 체감은 사용자가 고른 일반 세트의 ID와 당시 원문 kg·반복에 연결한 `여유 있었음 / 힘들었음 / 한계에 가까웠음` 자기보고다. 해당 세트가 삭제되거나 표기·kg·반복이 바뀐 체감은 그대로 저장할 수 없으며 현재 세트를 다시 확인한다.

[RIR 측정 실험](https://pubmed.ncbi.nlm.nih.gov/38595310/)에서도 주관적 추정의 오차와 조건에 따른 정확도 차이가 확인됐다. 위 세 가지 느낌을 특정 RIR 숫자·실패 판정·모든 세트의 노력 수준으로 환산하는 근거는 없다. 이 입력은 다음 보수적인 시도를 다듬기 위한 **제품 선택**이며, 기록 비교의 엄격한 조건을 자동 충족시키거나 능력·근성장을 인증하지 않는다. [ACSM 2026 공식 요약](https://acsm.org/wp-content/uploads/2026/03/Resistance-Training-Position-Stand-infographic.pdf)도 일반 건강한 성인에게 실행 가능한 점진적 훈련을 강조하며 복잡한 방식이나 실패 훈련을 필수로 보지 않는다. 특정 개인에게 같은 난도 선택이 최적이라는 보증은 아니다.

두 입력은 기존 기록에 없는 선택 필드여서 이전 저장·백업을 그대로 읽는다. 이미지 판독은 의도·체감·RIR을 지어내지 않고 가져온 뒤 사용자가 직접 남긴다. 같은 원본의 재가져오기는 확인한 의도·체감·메모를 보존하며, 이 주석을 이미지 원문 식별이나 운동 횟수 증가의 근거로 사용하지 않는다.

### 관찰에서 다음 시도로

`coachSession`은 세트 전체의 기록과 장비별 원문 이력을 이용한다. RIR·선행 세트 숫자가 완전히 같아야 유용한 원문 관찰과 다음 시도를 할 수 있다는 정책은 두지 않는다. [운동 순서 메타분석](https://pubmed.ncbi.nlm.nih.gov/32077380/)은 순서가 수행 맥락에 중요하다는 근거이지, 앞 운동의 반복 하나가 다르면 모든 참고를 끊으라는 근거는 아니다. 엄격한 수행 판정과 기록 기반의 조건부 다음 시도는 별개다.

첫 일반 세트와 전체 부하 구간의 실제 수행에서 유지 시도를 잡고, 특정 세트가 여유 있었다면 그 한 세트에서 1회 추가 선택을 제공한다. 탑세트·백오프·증량 구간은 따로 유지하며 고반복 뒤 세트 하나를 모든 세트의 목표로 바꾸지 않는다. 반복과 중량을 통한 진행은 [2022 훈련자 실험](https://pubmed.ncbi.nlm.nih.gov/36199287/)에서 비교됐지만, 항상 1회 추가가 모든 사용자에게 최적이라는 뜻은 아니다. 이 작은 변화는 **제품의 시험 선택**이며, 실제 반응·통증·목표에 따라 유지하거나 낮춘다. 최고 표시 중량을 곧바로 다음 시작값으로 쓰지 않으며 보조 저항은 외부 중량과 방향을 구분한다.

여러 운동의 표시 중량·반복·세트가 크게 줄면 의도적인 디로드·연습·시간 제한인지 먼저 묻는다. 중앙 표시 중량 70%, 세트 수 60%, 반복 합 65% 등의 문턱과 다수 종목 조건은 진단식이 아닌 질문 후보 필터다. [디로드 전문가 합의](https://pubmed.ncbi.nlm.nih.gov/37730925/)도 개인 맥락의 중요성을 다루며 하나의 숫자 감소로 디로드 필요성을 확정하는 보편식을 제공하지 않는다. 사용자가 확인한 디로드·복귀·테스트 등은 평소 수행 저하의 근거로 쓰지 않고, 이후 평소 기록은 앞선 평소 기준과 이어간다.

### 실제 수행에서 이어가는 RM 참고

[Reynolds 등(2006)의 원 연구](https://pubmed.ncbi.nlm.nih.gov/16937972/)는 최대 반복 시험에서 1RM을 예측했으며 낮은 반복의 시험이 더 정확했고 운동별 차이가 있었다. [반복과 %1RM의 2024 메타회귀](https://pmc.ncbi.nlm.nih.gov/articles/PMC10933212/)도 운동·개인에 따른 변이를 보고한다. 한 세트의 실제 중량·반복만으로 그 사람의 진짜 최대 능력이나 다음 성공 확률을 확정할 근거는 없다. 저반복 자체를 수행 테스트로 분류하지 않으며 사용자가 선택한 운동 목적을 우선한다.

순수 `training-capacity.js`는 양수 kg·1~10회 일반 세트에 Epley `kg × (1 + 반복/30)`와 Brzycki `kg × 36/(37−반복)`를 적용한다. 1회·여유 미기록은 실제 중량을 잠정 기준으로 남긴다. 범위는 두 산식의 차이지 신뢰구간이 아니다. 같은 종목·장비·규약·변형·부하 역할 안에서만 연결하며 머신·스미스·덤벨 표기 kg를 바벨 전체 kg로 환산하지 않는다. 고반복·맨몸·보조 중량·탄성 밴드는 kg RM을 외삽하지 않아도 실제 구성과 다음 시도는 제공한다.

RIR 누락은 코칭 중단 조건이 아니다. 숫자 RIR은 실제 세트의 반복에 더하되 합이 10회 이내일 때만 참고하고, 범위를 넘으면 실제 수행 반복 기준을 유지한다. 이 RIR 확장은 검증된 개인 예측식이 아닌 **제품 추정**이다. 세 가지 느낌은 숫자 RIR로 변환하지 않는다. 최근 기준은 42일 안의 가장 높은 잠정 추정, 역대 참고는 조회한 전체 기록의 최고 추정으로 분리한다. 같은 중량 노출은 디로드·통증 기록도 기억하지만 그런 날을 평소 수행 기준으로 끌어올리지 않는다. 미기록 기간은 휴식·능력 소실로 해석하지 않는다.

동일한 전체 일반 세트 구성이 서로 다른 최근 3일 이상 반복되면 이미 유지한 작업 기준으로 읽고 한 세트 1회 추가 또는 최소 부하 증가 중 하나를 시험하는 선택을 제공한다. 첫 세트가 같아도 뒤 세트가 좋아진 것을 전체 정체라고 부르지 않는다. 이 3일·42일 기준과 작은 변화, 경험 있는 수행 목표 사용자의 기존 세트 하나를 낮은 반복으로 바꾸는 선택은 **제품 설계**이지 최적 주기화나 보편 처방이 아니다. 같은 부하의 뒤 반복 급감, 추가 체감, 정확히 연결한 계획, 의도한 부담 조절 및 현재 통증이 다음 선택을 조정한다. RM 최고값으로 실제 일지·계획·영양 목표를 자동 변경하지 않는다.

체중 유지·감량은 영양 목표이며 운동 수행을 영구히 유지하라는 지시로 사용하지 않는다. 전체 수행이 안정되고 회복과 세트 여유가 괜찮다면 이 목표에서도 같은 작은 진행 선택을 제공하되, 현재 구성을 지키는 선택도 남긴다. 힘들었음·한계에 가까웠음·실제 RIR 0, 현재 회복·질병·통증, 운동 목적과 연결한 계획 범위가 다음 행동을 우선 조정한다. 표시하는 1회 추가는 수행 예측이나 자동 계획 수정이 아니라 실제 원문 세트에 연결한 **제품의 읽기 전용 선택**이다.

최근 42일은 전체 세트 구성이 연속해 반복된 구간으로도 읽는다. 이전의 여러 날 유지한 실제 작업 기준, 중간 변화, 현재 구성을 반복한 날짜를 따로 남기므로 중량·세트를 크게 낮춘 뒤 세 번 같아졌다고 그 감소를 지우지 않는다. 세트를 크게 늘린 뒤 첫 며칠 재현한 경우도 장기 적응으로 바꾸지 않는다. 반대로 같은 반복·세트를 더 무거운 부하에서 이어낸 기록은 이전 기준과 새 수행의 지속을 함께 보여 주고, 중량과 반복을 교환한 구성은 우열이나 근력 향상으로 판정하지 않는다. 다른 장비·규약·역할, 통증·비정규 목적·미검증 원문·충돌 기록은 평소 기준으로 끌어오지 않는다.

큰 변화의 선별 기준에 닿지 않는 완만한 진행도 별개의 실제 단계로 기억한다. 같은 운동·장비·표기·역할에서 독립 날짜에 반복해 남긴 전체 구성과 현재 구성을 최근 42일의 연속 단계로 보존하며, 마지막 6단계만 전달할 때는 전체 단계 수와 표본 여부를 명시한다. 이전에 같은 부하·세트 수로 더 이어낸 뒤 반복이 있다면, 현재 반복을 여러 번 유지했다는 이유로 그 출처를 지우지 않고 해당 세트의 한 번 더 이어갈 선택에 연결한다. 단계 기억은 성장·피로 원인·확정 강도 판정이 아니며 큰 변화 경고 기준이나 통증·건강·목적·직접 피드백·연결한 계획의 우선순위를 바꾸지 않는다.

현재 전체 일반 세트 구성이 같은 조건에서 이전 두 독립 날짜 이상 반복한 구성과 같고 그 사이 다른 실제 구성이 있으면, 마지막 구성과의 중량·반복 교환으로만 설명하지 않고 원래 작업 단계·중간 변화·이번 복귀를 실제 날짜와 세트 출처로 연결한다. 중간에 줄인 구성과 늘리거나 재배분한 구성을 구분하므로, 일시적으로 늘린 세트가 반드시 되찾아야 할 새 기준이 되지는 않는다. 첫 한두 번의 재현은 돌아온 구성을 유지하며 반응을 보고, 세 번째 실제 재현부터 건강·목적·여유·계획 조건에 맞는 작은 변화 선택을 다시 제공한다. 최고 중량 하나나 조회 날짜의 경과만으로 복귀를 만들지 않으며, 기록상 구성이 돌아온 것과 생리학적 회복·완치·새 능력은 구분한다. 기간·횟수·전체 구성 지문 대응은 제품 정책이다.

연속해 낮아진 구성에서 마지막 두 세트의 반복이 되살아났더라도, 이전 정상 구성과 현재를 직접 비교해 중량·세트 감소가 함께 남고 중간 구성도 이미 감소한 경우에는 그 전체 맥락을 보존한다. 반대로 반복 목표를 크게 바꾼 구성은 세트 수나 kg 하나로 감소·향상을 확정하지 않는다. 연결한 계획 밖의 실제 세트만 목표 확인 대상으로 삼고, 범위 안 세트와 계획 뒤 추가 세트는 별개로 이어간다. 뒤 반복이 줄었던 구간의 휴식·동작 제어 조언은 계획 확인과 함께 남기되, 범위 밖 세트를 그대로 유지하라는 지원 행동으로 덮지 않는다. 일반 세트 하나뿐이면 없는 나머지 세트의 유지를 안내하지 않는다.

이 에피소드의 선별 비율은 **제품의 맥락 선택**이다. 표시 최고 부하 약 15% 변화, 같은 구성의 반복·세트 약 25% 감소, 세트 50% 이상이면서 2개 이상 증가를 중요한 구성 변경의 후보로 본다. 앞뒤 반복 제어와 현재 회복도 함께 읽으며, 확대 구성은 실제 재현이 7일 이상 이어지고, 낮춘 구성은 14일 이상·서로 다른 4일 이상 이어졌을 때 다시 작은 진행 선택을 제공할 수 있다. 이 기간·비율·뒤 반복 80% 기준은 생리학적 적응 완료나 손상 위험의 검증 기준이 아니다. 한 번의 최고 기록을 평소 기준으로 삼지 않고, 실제 기록이 추가되지 않은 채 조회 날짜만 지나간 것을 새로운 재현·회복 근거로 세지 않는다. 명시적 세트 체감·목적·계획·현재 상태가 최종 선택을 조정하므로 기간만 채웠다고 자동 증량하지 않는다.

### 전체 세트와 세션의 판단 연결

`training-coaching.js`는 실제 일반 세트의 순서·중량별 구간·원문 ID와 비교 출처를 보존한다. 새 고중량 뒤의 반복 감소, 기본 구간 유지와 무거운 구간 감소, 뒤 반복의 회복, 고중량 작업 세트 확대, 낮은 부하 세트의 준비 표기 전환을 별개의 관찰로 읽는다. 전체 반복 합이 같아도 서로 반대 방향으로 변한 구간을 상쇄하지 않는다. 같은 날짜의 반복 블록·충돌 출처·통증·의도한 부담 조절·예전 미검증 OCR을 평소 능력의 기준으로 섞지 않는다. 오래된 중량 경험은 기억하되 바로 따라잡을 목표로 삼지 않는다.

세션 조율은 현재 메인·우선 부위, 새 부하의 적응, 관련 운동의 구성 변경과 뒤 수행 조정 과제를 함께 본다. 요약의 대표 진행 종목은 강조할 초점이며, 다른 종목의 진행 금지가 아니다. 같은 주동 부위·동작의 중요한 변화 또는 해당 주동 부위의 직접 세트 증가가 있을 때만 추가 변화와 조율하고, 별개 종목의 안정적인 수행·뒤 세트 과제·작은 진행 선택은 본문에 유지한다. 보조 부위만 겹치거나 전체 세트 수만 늘었다는 이유로 전부 보류하지 않는다. 이 관련성·조율 기준은 **제품 선택**이지 피로율이나 생리학적 진행 금지 판정이 아니다. 사용자 목표·체감·계획을 반영하며 표시 정렬을 실제 수행 순서나 조언의 우선순위로 바꾸지 않는다.

명시적으로 회전 제어·견갑 제어·가동성·유산소로 분류한 동작은 메인 저항 작업의 진행 조율에서 따로 다룬다. 외회전·W 레이즈의 세트 추가만으로 프레스까지 증가 금지로 바꾸지 않지만 원형 세트·부위 집계와 식사·전체 활동 맥락은 보존한다. 제어 동작 자체의 RIR 0·힘들었음·한계 느낌·통증은 일반적인 기술 연습 문구로 덮지 않는다. 이 구분은 동작별 피로·자극량의 정량 환산이나 재활 처방이 아니다.

선택적 확인 질문의 답변은 주제와 당시 전체 세트 스냅샷으로 저장한다. 의도한 반복 목표는 실패로 평가하지 않고, 예상 밖 수행은 유지된 구간을 남긴 채 달라진 구간부터 재확인한다. 원문 숫자·표기·세트 구성이 바뀌면 기존 답변을 재사용하지 않는다. 이 답변을 숫자 RIR이나 전 세션의 운동 목적으로 확대하지 않는다. 답변 전에도 실제 수행에서 다음 행동을 제공한다.

같은 날짜의 실제 일지에 정확히 연결한 계획은 반복 범위와 목표 RIR을 함께 참고한다. 지정한 장비·중량 규약·부하가 실제 세트와 맞는 범위에서만 계획한 여유를 대응하고, 미입력 RIR은 미달이 아니다. 실제 보고 여유가 목표보다 적은 세트는 추가 반복보다 의도한 여유를 맞추는 선택을 먼저 제공한다. 충분히 쉬고 동작을 확인해도 버거우면 부하나 반복을 조절할 수 있지만 새 kg를 계산하거나 휴식만으로 목표 여유를 보장하지 않는다. 다른 세트와 추가 세트는 별개로 보존하며 통증·건강·운동 목적이 우선한다. 이 연결은 저장 계획과 자기보고를 조율하는 제품 선택이지 정확한 피로·능력 손실·손상 위험 판정이 아니다.

AI 전달은 실제 세트·출처, 해석 가설, 다음 행동 후보와 RM 모델을 구분한다. AI는 가설과 제품 제안을 재검토할 수 있지만 원문이나 입력하지 않은 조건을 만들어서는 안 된다. 전달 예산으로 상세 이력이 줄어도 전체 집계·원문 구간 수·표본 여부를 남긴다. 실제 상담의 출처 검사와 합성 사례 재독은 오류를 찾는 검증이지 자유 답변의 모든 상황·원인 추론·안전성을 보증하는 검증이 아니다.

현재 수행의 특정 일반 세트에서 반복 한 번을 더 시험하는 숫자는 별도의 구조화된 진행 제안이다. 실제 세트 ID·kg·반복과 `다음 반복 = 현재 반복 + 1`을 확인한 제안만 AI가 인용할 수 있고, 실제 수행·최대 능력·이미 적용한 계획으로 등록하지 않는다. `product-choice` 출처의 `estimated:true`는 아직 수행하지 않은 선택을 표시하며 능력 예측을 뜻하지 않는다. 새로운 kg·RIR·식사 처방 숫자를 자유롭게 만드는 허용은 아니다. 미룬 후보는 이후 대안으로 구분하며 같은 블록의 앞 세트에서 변화를 시험하면 뒤 구간은 이번 반복을 유지한다. 연결한 계획의 반복 상단을 넘는 제안은 계속 반복을 올리는 대신 그 범위에서의 유지·최소 부하 변경 검토로 조정한다.

### 일지 전체 관찰과 표시 우선순위

최근 코칭 요약은 일지 전체의 종목·세트·확인 상태를 보여 주며 한 종목의 표시 중량을 전체 운동의 향상·저하로 대표하지 않는다. `reviewSession`은 선택한 세션까지의 관찰만 사용해 각 원문 블록의 세트와 비교 근거를 제공한다. 장비·중량 표기·순서 맥락이 다른 블록, 같은 날 복수 세션과 A→B→A를 하나의 수행 숫자로 합치지 않는다. 숫자가 없는 운동도 표시하며 조회 범위가 부분적이면 날짜 범위를 명시한다.

메인 운동은 사용자가 지정한 표시 선호이며 장비를 강제로 한 개만 쓰게 하는 규칙이 아니다. 우선순위순의 메인 → 설정 우선 부위의 직접 자극 운동 → 복합 동작 → 나머지와 일지순의 원문 순서는 **제품의 화면 배치 선택**이다. 같은 단계는 원문 순서로 유지한다. 고중량·총볼륨·변화율로 생리학적 중요도를 계산하지 않으며 복합 동작 우선을 개인의 최적 운동 순서로 주장하지 않는다. 표시 정렬·메인 선호는 실제 수행 순서·회복 평가·영양 목표·계획 처방을 변경하지 않는다.

`src/training.js`는 DOM·저장소·시간 전역에 의존하지 않는 UMD 모듈이다. `MacroTraining`과 Node의 `module.exports`로 같은 API를 제공한다. 기준 날짜가 없고 기록도 없으면 날짜를 만들지 않는다. 기록만 제공된 경우 최신 기록 날짜를 분석 끝으로 사용한다.

공개 API는 `catalog`, `muscleLabels`, `resolveExercise(rawName, mappings)`, `analyze(records, options)`, `reviewSession(analysis, options)`, `coachSession(analysis, options)`, `recommendProgram(profile, settings, analysis, preferences)`, `createProgram(draft, options)`, `createAssignment(program, dayId, date, id)`, `evaluateAssignment(assignment, records)`, `adjustAssignment(assignment, change, context)`다. `src/training-store.js`는 실제 일지와 계획·날짜 배치·선호·기억·후속 약속을 별도로 검증하며 중앙 백업에 포함한다. 실사용자의 일지나 이미지를 테스트 fixture에 넣지 않았다. 테스트는 합성 자료로 작성했다.

검증 범위: 기간 경계·미래·오류 날짜, 미입력과 숫자 0 구분, 원문 표시, 준비 세트 제외, 직접·간접 집계, 같은 날 두 세션, 중복·충돌 ID, 장비·규약·RIR 불일치, 관찰값 보존, 반복 저하와 자기보고 조합, 통증 우선, 임상·연령 지원 범위, 프로그램 조합, 시간 증가 시 세트 수 비감소, 기록 세트 추가 시 집계의 정확한 증가, 입력 불변성. 저장 계획은 배치 당시 목표 보존, 미기록 상태, 실제 일지 연결, 미확인 값과 계획 비교, 명시적 조정·재검토, 미등록 운동 보존, 백업 왕복과 좁은 화면 흐름도 검증한다. 테스트 통과는 임상적 검증이나 개인별 정확도 보증이 아니다.

판단 기록: README·영양 근거 문서·제품 검토 스킬과 실제 추출/기록 경계를 확인하고 `npm run preflight:product`를 통과했다. 단순 kg×반복 그래프나 생성형 문장만으로 코치를 구현하는 대신, 실제 기록·부위 분류·비교 판정·프로그램 예시를 분리하는 순수 엔진을 선택했다. 반증 조건은 미확인 장비를 합쳐 성장으로 표현하거나, 미입력을 0으로 만들거나, 같은 날 두 세션으로 반복 저하를 확정하거나, 통증 상태에서 자동 증량을 권하거나, 프로그램 생성이 사용자 기록·영양 목표를 바꾸는 경우다.

보류: 동작 영상·관절 통증 평가, 머신 저항 교정, 경기 일정에 따른 종목별 주기화, 실제 근비대 측정, 부상 재활 및 질환별 처방. 구현된 일정·기록·조정 흐름을 이 보류 영역의 완성으로 표현하지 않으며, 실제 사용 피드백과 독립적인 개인별 타당성 평가는 여전히 필요하다.
