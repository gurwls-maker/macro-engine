# Macro Engine

운동·식사·몸 상태를 기억하고 다음 행동을 함께 정하는 개인 코칭 앱입니다. 영양 계산, 세트 일지, 수행 변화, 회복과 프로그램을 연결했습니다. 현재 버전은 **9.0.0-rc.2**입니다.

`npm ci` 후 `npm start`로 표시된 로컬 주소를 엽니다(기본 `http://127.0.0.1:4173`). 설치되고 로그인된 Codex CLI가 있으면 별도 API 키 없이 개인 대화와 이미지 판독을 사용할 수 있습니다. 로그인·사용 한도가 없어도 직접 기록과 기록 코치는 동작합니다.

`index.html`을 직접 열어도 계산·수동 기록·JSON 교환·기록 코치는 동작합니다. **파일 주소와 HTTP 주소의 브라우저 기록은 서로 다릅니다.** 기존 파일 주소에서 전체 백업을 내려받아 새 주소의 데이터 화면에서 확인하고 복원하세요. PC 기록도 미리보기 후 명시적으로 선택하며 빈 브라우저가 원본을 자동 덮어쓰지 않습니다.

## 제품

- 내 기준: 성별, 나이, 키, 체중, 측정 당시 체성분, 실제 운동 경력, 종목, 일상 활동, 목표와 건강 맥락.
- 오늘: 식사·혼합 운동·체중·체성분 기록, 총열량을 보존하는 탄수화물/지방 배분, 완료 전후를 구분한 조언.
- 앱코치: 최근 운동·식사·컨디션을 연결한 대화. 기록 코치는 규칙 기반 해석이며 Codex는 개인 AI 응답입니다. 급성 증상은 AI를 기다리지 않고 중단·진료 안내를 우선합니다.
- 운동: 세트·RIR·통증·메모, 지난 운동 재사용, 장비·운동명 연결, 직접/간접 부위와 실제 수행 변화. 날짜·시간·장비·우선 부위에 맞춘 시작 프로그램은 실제 운동 기록과 구분합니다.
- 이미지: 운동 일지·식사/라벨·체성분을 초안으로 판독하고 날짜·분량·숫자를 확인한 뒤 반영합니다. 미확인 숫자는 null입니다. 이미지 확인함에서 이전 초안을 다시 열 수 있습니다.
- 변화: 날짜별 기록, 최근 체중 그래프와 주간 중앙값, 같은 목표로 완료한 날의 식사 요약.
- 데이터: 검증 후 복원하는 전체 JSON 백업(일지·매핑·대화 포함), UTF-8 CSV, 이전 버전 원본의 읽기 전용 보관. 이미지는 전체 JSON에 포함하지 않습니다.

숫자는 측정값이나 진단이 아닌 시작 추정입니다. 자동 목표는 일반 성인 범위에 한정하며 성장기, 임신·수유, 치료 식이·섭식 문제, 일부 극단 체격·훈련 상태에는 개별 계획을 안내합니다. 이 경우에도 기록은 사용할 수 있습니다. 점수를 건강 판정으로 해석하는 종합점수는 제공하지 않습니다.

## 개발과 검증

```sh
npm ci
npm run setup:browsers
npm run preflight:product
npm run test:all
```

로컬에서는 설치된 Chrome도 테스트에 사용할 수 있습니다. GitHub CI는 Playwright Chromium을 설치합니다. 실행 앱에 테스트나 과거 시뮬레이터를 싣지 않습니다.

과학적 근거와 모델 선택: [영양](docs/evidence.md), [훈련](docs/training-evidence.md). 재구성 판단: [docs/rebuild.md](docs/rebuild.md). 다른 머신의 kg를 환산하거나 미기록 날짜를 휴식으로 채우지 않습니다. 프로그램을 여는 것만으로 운동·영양 목표가 바뀌지 않습니다.

`npm run test:coach:live`는 별도 선택 검증이며 로그인 계정 사용량으로 합성 대화·이미지를 실제 Codex에 보냅니다. 일반 테스트/CI는 AI를 호출하지 않습니다.

기존 v8 코드·문서·테스트는 Git 태그 `archive/v8-before-rebuild-2026-10-05`에서 복구할 수 있습니다. 이전 브라우저 저장 키와 `user-data/`는 변경하지 않습니다. 새 버전 저장 키는 `macro-engine.v9`입니다.

## Codex 운동 일지

기존 외부 폴더의 원본을 유지하고 개인 설정·추출·교정·PC 상태·업로드·AI 초안은 Git에서 제외된 `user-data/coach/`에 저장합니다. 개인 경로는 로컬 설정에만 있습니다. 폴더 확인은 새/변경 내용만 찾고 이미 처리한 판독을 재사용합니다. 브라우저의 운동 가져오기로 캐시를 미리보고, 중복 후보·변경 원문은 비교 확인합니다. 상시 감시나 자동 AI 호출은 없습니다.

```sh
npm run diary -- scan
npm run diary -- context --from 2026-09-01 --to 2026-10-05
npm run coach -- context --date 2026-10-06
npm run coach -- propose --file user-data/coach/proposal.json
npm run coach -- propose --file user-data/coach/proposal.json --apply
```

제안 형식은 `{schemaVersion:1, expectedDigest, state}`입니다. 기본 동작은 미리보기이고 `--apply`도 완료한 날짜의 변경과 기존 기록 삭제는 거부합니다. 완료일은 앱에서 먼저 다시 열어야 하며 오래된 digest도 거부합니다. Codex 채팅에서도 연결된 앱 상태로 코칭하고 확인한 기록을 제안할 수 있습니다. 앱 새로고침 후 PC 기록 확인으로 복원합니다.

동일 이미지 사본은 재사용하고 과거 OCR의 미검증 표시를 유지합니다. 전체 바이트 검사는 `scan --verify-all`입니다. 원본 폴더가 오프라인이면 마지막 성공 캐시와 시점을 구분합니다. Git 제외는 암호화·자동 백업이 아니므로 **외부 원본과 `user-data/coach/` 전체를 함께 개인 백업**하세요.

## PC 연결과 AI 경계

PC 연결 뒤 변경은 브라우저와 `app-state.json`에 저장합니다. 다른 브라우저/서버의 변경은 CAS·공유 락으로 차단하며 저장 실패 시 브라우저 기록을 유지하고 재연결 확인을 제공합니다. 서버는 루프백에만 열리고 개인 경로를 정적 웹 파일로 제공하지 않습니다. 비정상 종료의 잔여 락은 프로세스 종료를 확인해 복구하며 자동으로 다른 프로세스를 죽이지 않습니다.

Codex 질문에는 선택 날짜·프로필·제한된 최근 식사·운동·컨디션·대화가 전달됩니다. 이미지 판독은 선택 이미지·날짜·추가 맥락만 보내며 전체 사진 폴더를 보내지 않습니다. 계정 사용량을 사용하고 오독할 수 있어 반영 전 확인이 필요합니다. 프로그램·판독 결과는 생리학적 확정이나 의료 처방이 아닙니다.

Codex는 ephemeral/read-only로 실행하고 셸·앱/플러그인·브라우저·컴퓨터·다른 에이전트·후크·검색 기능을 끕니다. 출력은 구조·종류·숫자 범위를 재검증합니다. 이것이 모든 AI 오류나 기기 침해를 막는 보증은 아닙니다.
