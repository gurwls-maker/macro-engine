# Macro Engine

운동·식사·몸 상태를 기억하고 다음 행동을 함께 정하는 개인 코칭 앱입니다. 영양 계산, 세트 일지, 수행 변화, 저장한 프로그램과 다음 점검을 연결했습니다. 현재 버전은 **9.0.0-rc.3**입니다.

`npm ci` 후 `npm start`로 표시된 로컬 주소를 엽니다(기본 `http://127.0.0.1:4173`). 설치되고 로그인된 Codex CLI가 있으면 별도 API 키 없이 개인 대화와 이미지 판독을 사용할 수 있습니다. Codex를 쓸 수 없어도 직접 기록·지난 기록 재사용·기록 요약과 사진 보관은 동작합니다. 사진 보관만으로 숫자 일지가 완성되지는 않습니다.

`index.html`을 직접 열어도 계산·수동 기록·JSON 교환·기록 요약은 동작합니다. 사진의 PC 보관과 AI 연결에는 로컬 서버가 필요합니다. **파일 주소와 HTTP 주소의 브라우저 기록은 서로 다릅니다.** 기존 파일 주소에서 전체 백업을 내려받아 새 주소의 데이터 화면에서 확인하고 복원하세요. PC 기록도 미리보기 후 명시적으로 선택하며 빈 브라우저가 원본을 자동 덮어쓰지 않습니다.

## 제품

- 내 기준: 성별·나이·체격·측정 당시 체성분·실제 운동 경력·종목·목표·건강 맥락. 단백질의 아래쪽/기본/높은 쪽과 유지에 더 가까운 감량·증량을 선택할 수 있습니다.
- 활동: 기존 간편 모드와 선택적 24시간 상세 모드. 기본 수면·업무·생활 시간, 요일 예외와 그날의 실제 시간은 구분합니다. 걷기·달리기의 속도·경사 상세 추정은 지원 조건 안에서만 사용합니다. 자주 하는 운동은 이름 붙여 저장하고 입력값을 확인한 뒤 사용합니다.
- 오늘: 배치한 운동·실제 일지·다시 확인할 점검을 먼저 보고 사진·지난 운동·식사를 빠르게 기록합니다. 컨디션은 선택 사항입니다. 식사 구분·메모·자주 먹는 식사, 전날 식사 선택 복사와 중복 후보 확인, 술의 양·도수·개수에서 순알코올 계산을 지원합니다. 탄수·지방 배분은 총열량·단백질을 보존하며 최근 완료 기록을 참고한 선택안도 확인 후 적용합니다.
- 앱코치: 자유로운 상담은 Codex 대화, 수치와 정해진 확인 항목은 별도 기록 요약입니다. 질문의 날짜·기간·운동·부위를 조회하고 현재 조회 범위와 빠진 조건을 표시합니다. 같은 기록과 계산 함수를 사용하며 AI가 상담마다 과거 이미지를 다시 읽지는 않습니다. 개인 맥락·합의·다음 점검은 확인 후 저장하고 질문과 관련된 과거 기록 일부를 재사용합니다. 감지한 급성 증상은 AI를 기다리지 않고 안전 안내를 우선합니다. AI 연결이 없으면 대화 대신 기록 요약을 사용할 수 있으며 동등한 상담 능력으로 표시하지 않습니다.
- 운동: 세트·RIR·통증·메모, 지난 운동 재사용, 장비·운동명 연결, 직접/간접 부위와 수행 변화. 시작 프로그램을 저장·편집하고 날짜에 배치한 뒤 실제 기록과 비교합니다. 중량·부담 감소는 사용자가 선택하고 다시 확인할 날짜를 남깁니다.
- 이미지: 여러 운동 일지·식사/라벨·체성분 사진을 선택하거나 붙여넣어 Codex 없이 먼저 보관할 수 있습니다. AI 판독은 별도로 선택하며 한 장씩 요청합니다. 새로고침 뒤 남은 대기는 사용자 선택 없이 재개하지 않습니다. 원문 옆의 전체 판독 숫자·장비·미확인 항목을 확인하고 수정한 뒤 일지에 반영합니다. 실패한 사진만 재시도할 수 있으며 미판독 사진은 실제 기록이나 합계에 포함하지 않고 미확인 숫자는 null입니다. 이미지 확인함에서 보관 사진과 이전 초안을 다시 열 수 있습니다.
- 선택·점검: 저장한 프로그램 선택·일정 이동·탄수/지방 배분·계획 부담 조절을 변경 전후와 이유·다음 점검 날짜가 있는 초안으로 확인합니다. 적용 전에 관련 기준이 바뀌면 다시 비교하며 취소·가능한 범위의 복구를 지원합니다. 실제 실행 자기보고와 저장된 수행·식사·컨디션을 나눠 살펴보고 유지·수정·판단 보류를 남깁니다. AI 문장이 임의의 숫자 처방이나 자동 변경으로 이어지지는 않습니다.
- 변화: 7/14/28/42일의 섭취와 당시 목표, 체중·체지방률·골격근량 관찰 그래프와 날짜별 표. 미기록·기록 중·완료를 구분하며 누락을 0섭취나 휴식으로 채우지 않습니다.
- 데이터: 전체 JSON 백업, 날짜별 기록 합치기 미리보기, UTF-8 CSV, 이전 원본 읽기 전용 보관. 전체 백업에는 일지·매핑·저장 프로그램·배치한 처방·대화·개인 맥락·점검이 포함되지만 이미지 파일은 포함하지 않습니다.

운동명 앞의 `STA7000`, `디랙스`, `인피니티` 또는 `[장비명] 운동명`, `장비명 | 운동명` 표기는 기존 일지에도 자동 반영합니다. 원암·덤벨은 한쪽, 바벨은 전체 중량을 기본으로 읽으며 실제 kg를 환산하지 않습니다. 직접 지정한 장비·기준과 확인한 매핑이 우선이고, 이름 단서가 충돌하면 미확인으로 남깁니다. 브랜드 표기만으로 같은 물리적 머신이나 저항을 보증하지 않습니다.

계산한 소모량과 목표는 측정값이나 진단이 아닌 시작 추정입니다. 자동 목표는 일반 성인 범위에 한정하며 성장기, 임신·수유, 치료 식이·섭식 문제, 일부 극단 체격·훈련 상태에는 개별 계획을 안내합니다. 이 경우에도 기록은 사용할 수 있습니다. 점수를 건강 판정으로 해석하는 종합점수는 제공하지 않습니다.

## 사용 흐름

1. 내 기준을 입력합니다. 시간표가 불확실하면 간편 활동 모드로 시작하고 모르는 체성분·경력을 채워 넣지 않습니다.
2. 오늘 먹은 식사와 실제 운동·몸 상태를 기록합니다. 이미지 판독이나 재사용 식사도 저장 전에 내용을 확인합니다. 하루 완료는 당시 목표를 고정합니다.
3. 운동의 프로그램에서 초안을 저장하고 운동별 구성과 날짜를 정합니다. 계획한 반복·RIR·휴식은 실제 수행 숫자와 따로 보존됩니다.
4. 앱코치에서 최근 기록을 함께 살펴보고 기억할 제약·합의와 다음 점검을 확인합니다. 계획 생성·AI 답변만으로 식사 목표나 실제 운동 기록이 변경되지는 않습니다.
5. 변화 화면에서 기록 범위와 당시 목표를 비교하고 전체 백업을 보관합니다. 날짜별 합치기는 현재 프로필·훈련·대화를 유지하며 완료일 교체를 막고, 전체 복원은 별도 확인 후 선택합니다.

상세 활동은 Mifflin 안정시대사량, FAO 활동비와 운동 추정을 조합한 제품 모델입니다. 간편 모드보다 개인에게 더 정확하다는 검증은 없습니다. 속도·경사 식도 정상상태 조건의 근사이며 심폐능력 측정이나 모든 종목의 훈련 처방은 아닙니다.

## 개발과 검증

```sh
npm ci
npm run setup:browsers
npm run preflight:product
npm run test:all
```

로컬에서는 설치된 Chrome도 테스트에 사용할 수 있습니다. GitHub CI는 Playwright Chromium을 설치합니다. 실행 앱에 테스트나 과거 시뮬레이터를 싣지 않습니다.

과학적 근거와 모델 선택: [영양](docs/evidence.md), [훈련](docs/training-evidence.md). 재구성 판단: [docs/rebuild.md](docs/rebuild.md). 다른 머신의 kg를 환산하거나 미기록 날짜를 휴식으로 채우지 않습니다. 프로그램을 여는 것만으로 운동·영양 목표가 바뀌지 않습니다.

`npm run test:coach:live`는 별도 선택 검증이며 로그인 계정 사용량으로 합성 대화·이미지를 실제 Codex에 보냅니다. 일반 테스트/CI는 AI를 호출하지 않습니다.

기존 v8 코드·문서·테스트는 Git 태그 `archive/v8-before-rebuild-2026-10-05`에서 복구할 수 있습니다. 이전 브라우저 저장 키와 `user-data/`는 변경하지 않습니다. 새 버전 저장 키는 `macro-engine.v9`입니다.

## Codex 운동 일지

기존 외부 폴더의 원본을 유지하고 개인 설정·추출·교정·PC 상태·업로드·AI 초안은 Git에서 제외된 `user-data/coach/`에 저장합니다. 개인 경로는 로컬 설정에만 있습니다.

앱 안에서 이미지를 직접 선택하면 우선 사진과 메모만 보관하거나 명시적으로 Codex 판독을 요청할 수 있습니다. 사진 보관에는 Codex가 필요하지 않지만 자동으로 운동명·중량·반복·식사·체성분을 읽는 기능에는 현재 Codex가 필요합니다. AI가 없으면 직접 입력·지난 운동/식사 재사용·검증한 JSON 가져오기를 사용하거나 사진을 남겨 두고 나중에 판독할 수 있습니다. 같은 이미지의 다른 이름·종류·메모가 다시 올라오면 처음 보관한 정보를 유지하고 차이를 알립니다.

업로드한 이미지와 판독 결과는 이 PC에 보관하며 같은 요청의 기존 결과와 이미지 확인함을 재사용합니다. 기존 외부 일지 폴더 전체를 앱이 자동으로 시각 판독하는 기능은 아닙니다. 폴더 방식은 Codex의 `coach-diary` 스킬과 아래 CLI가 새/변경 후보를 찾고, 필요한 이미지만 판독·교정해 캐시에 등록하는 흐름입니다. 앱의 운동 가져오기는 이 캐시를 미리보고 중복·변경 원문을 비교한 뒤 적용합니다. 상시 감시나 요청 없는 자동 AI 호출은 없습니다.

```sh
npm run diary -- scan
npm run diary -- context --from 2026-09-01 --to 2026-10-05
npm run coach -- context --date 2026-10-06
npm run coach -- propose --file user-data/coach/proposal.json
npm run coach -- propose --file user-data/coach/proposal.json --apply
```

제안 형식은 `{schemaVersion:1, expectedDigest, state}`입니다. 기본 동작은 미리보기이고 `--apply`도 완료한 날짜의 변경과 기존 기록 삭제는 거부합니다. 완료일은 앱에서 먼저 다시 열어야 하며 오래된 digest도 거부합니다. Codex 채팅에서도 연결된 앱 상태로 코칭하고 확인한 기록을 제안할 수 있습니다. 앱 새로고침 후 PC 기록 확인으로 복원합니다.

동일 이미지 사본은 재사용하고 과거 OCR의 미검증 표시를 유지합니다. 전체 바이트 검사는 `scan --verify-all`입니다. 원본 폴더가 오프라인이면 마지막 성공 캐시와 시점을 구분합니다. Git 제외는 암호화·자동 백업이 아니므로 **외부 원본과 `user-data/coach/` 전체를 함께 개인 백업**하세요.

## PC 연결과 AI 경계

PC 연결 뒤 변경은 브라우저와 `app-state.json`에 저장합니다. 다른 브라우저/서버의 변경은 CAS·공유 락으로 차단하며 저장 실패 시 브라우저 기록을 유지하고 재연결 확인을 제공합니다. 서버는 루프백에만 열리고 개인 경로를 정적 웹 파일로 제공하지 않습니다. 비정상 종료의 잔여 락은 프로세스 종료를 확인해 복구하며 자동으로 다른 프로세스를 죽이지 않습니다.

Codex 질문에는 선택 날짜·프로필·제한된 최근 식사·운동·컨디션·대화, 사용자가 저장한 개인 맥락·선택·점검, 질문에서 조회한 기간의 전체 집계와 제한된 원문 일부가 전달됩니다. 명시한 3개월의 집계를 최근 28일로 대체하지 않지만 수행 변화 판정은 기존 계산기가 지원하는 28일 이하 구간 내부만 사용합니다. 현재 질문의 새 진술은 저장된 컨디션과 별도로 전달하고 자동 저장하지 않습니다. 자유문장을 의미적으로 빠짐없이 찾는 검색은 아니며 모호한 조건은 확인 필요로 표시합니다. 대량 자료에서는 원문·이전 대화·일부 수행 비교를 명시적으로 축약하고 전체 집계·기간·출처 건수는 유지합니다. 이미지 판독은 선택 이미지·날짜·추가 맥락만 보내며 전체 사진 폴더를 보내지 않습니다. 계정 사용량을 사용하고 오독할 수 있어 반영 전 확인이 필요합니다.

기록 요약과 AI 상담은 별도의 기록 분석 엔진이 아닙니다. 상담 직전에 앱이 같은 순수 계산 함수로 최신 집계를 만들고, 출처 있는 계산값과 제한된 원문 세트를 AI에 함께 전달합니다. 이 계산에는 AI 사용량이 들지 않습니다. AI는 질문별 의미·가능성·다음 행동을 해석하지만 원본 이미지는 다시 받지 않습니다. 따라서 앱과 AI는 입력·분류 오류를 공유할 수 있으며 서로 독립적인 검증으로 취급하지 않습니다. 현재 Codex 연결을 대신할 앱 자체 AI 서비스는 구현하지 않았습니다.

앱은 기록·모델 추정의 날짜와 출처를 붙인 수치 목록을 AI에 전달하고, 답변의 구조화된 수치 근거와 감지한 숫자·단위를 대조합니다. 근거가 맞지 않는 응답은 보류합니다. 이는 자유문장의 인과관계·의학적 타당성·개인 안전성을 검증하는 장치가 아닙니다. AI의 다음 점검 제안도 사용자 확인 전에는 저장하지 않으며 영양·훈련 처방을 자동 변경하지 않습니다.

새 질문의 숫자는 자동으로 확인된 기록 값으로 승격하지 않습니다. 예를 들어 아직 저장하지 않은 수면 시간을 AI가 숫자로 그대로 인용하면 현재 수치 검사에서 답변이 보류될 수 있습니다. 새 진술의 원문은 전달되지만 모든 자유문장 수치를 정확히 분류하는 기능은 아직 지원하지 않습니다.

Codex는 ephemeral/read-only로 실행하고 셸·앱/플러그인·브라우저·컴퓨터·다른 에이전트·후크·검색 기능을 끕니다. 출력은 구조·종류·숫자 범위를 재검증합니다. 이것이 모든 AI 오류나 기기 침해를 막는 보증은 아닙니다.
