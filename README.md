# Macro Engine

일반 성인의 식사·운동·몸 상태를 기록하고 개인화한 섭취 시작점을 제시하는 로컬 앱입니다. 현재 버전은 **9.0.0-rc.1**입니다.

`index.html`을 브라우저에서 열면 동작합니다. 서버·계정·외부 CDN이 필요하지 않습니다. 선택적으로 `npm start`로 로컬 HTTP 주소에서도 열 수 있습니다. 파일 주소와 HTTP 주소의 브라우저 저장소는 서로 다르므로 이동할 때 전체 백업을 사용합니다.

## 제품

- 내 기준: 성별, 나이, 키, 체중, 측정 당시 체성분, 실제 운동 경력, 종목, 일상 활동, 목표와 건강 맥락.
- 오늘: 식사·혼합 운동·체중·체성분 기록, 총열량을 보존하는 탄수화물/지방 배분, 완료 전후를 구분한 조언.
- 앱코치: 당일 기록·완료 여부·수면·허기·에너지·식사 여건·예정 운동과 최근 수행을 구분하는 로컬 영양·회복 코칭. 이미지 해석이나 개인 AI 자유대화는 아직 연결하지 않았습니다.
- 변화: 날짜별 기록, 최근 체중 그래프와 주간 중앙값, 같은 목표로 완료한 날의 식사 요약.
- 데이터: 검증 후 복원하는 전체 JSON 백업, UTF-8 CSV, 이전 버전 원본과 저장 당시 값의 읽기 전용 보관.

숫자는 측정값이나 진단이 아닌 시작 추정입니다. 자동 목표는 일반 성인 범위에 한정하며 성장기, 임신·수유, 치료 식이·섭식 문제, 일부 극단 체격·훈련 상태에는 개별 계획을 안내합니다. 이 경우에도 기록은 사용할 수 있습니다. 점수를 건강 판정으로 해석하는 종합점수는 제공하지 않습니다.

## 코드

| 위치 | 책임 |
| --- | --- |
| `src/nutrition.js` | 입력 검증, 목표, 운동 소모 추정, 등열량 배분 |
| `src/storage.js` | 저장, 스키마 검증, 백업, 이전 데이터 보관 |
| `src/insights.js` | 섭취 합계, 완료 여부, 추세와 조언 우선순위 |
| `src/coach.js` | 확인된 맥락과 최근 기록의 읽기 전용 해석, 다음 행동과 추가 질문 |
| `src/app.js` | 브라우저 화면, 입력, 기록·복원 상태 전환 |
| `src/styles.css` | 데스크톱·모바일 화면 |
| `tests/` | 계산·저장 단위 검증과 실제 브라우저 검증 |
| `assets/` | 로컬 Lucide 아이콘과 원문 라이선스 |

## 개발과 검증

```sh
npm ci
npm run setup:browsers
npm run preflight:product
npm run test:all
```

로컬에서는 설치된 Chrome도 테스트에 사용할 수 있습니다. GitHub CI는 Playwright Chromium을 설치합니다. 실행 앱에 테스트나 과거 시뮬레이터를 싣지 않습니다.

과학적 근거와 모델 선택: [docs/evidence.md](docs/evidence.md). 재구성 판단·의도 보존·검증 결과: [docs/rebuild.md](docs/rebuild.md).

기존 v8 코드·문서·테스트는 Git 태그 `archive/v8-before-rebuild-2026-10-05`에서 복구할 수 있습니다. 이전 브라우저 저장 키와 `user-data/`는 변경하지 않습니다. 새 버전 저장 키는 `macro-engine.v9`입니다.
